# FranklyOpen — Privacy Policies

Public home of the privacy policies for all FranklyOpen games, served
via GitHub Pages.

**The store-listing URL (use this for every game):**
https://franklyopen-com.github.io/PrivacyPolicy/

One shared policy covers every game we publish, because all our games
are built to the same rules: no data collection, no network, no ads, no
purchases (see each game's charter). Sources:

- `index.html` — the published page (canonical)
- `policy.md` — markdown source, kept in sync by hand

## Adding a game

Nothing to do, if the game follows the rules — the shared policy
already covers it. Optionally add it to the "including ..." list in
both files for clarity.

## If a game ever needs its own policy

Only if a game deviates from the shared rules (it shouldn't):

1. Create `games/<game-slug>/index.html` with that game's policy.
2. Its URL becomes
   `https://franklyopen-com.github.io/PrivacyPolicy/games/<game-slug>/`.
3. Use that URL in that game's store listings, and note the exception
   in the shared policy.
