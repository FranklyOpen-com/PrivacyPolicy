# Privacy Policy — Cannonball Cove

**The short version: this game collects nothing, sends nothing, and
contains nothing to buy.**

Cannonball Cove is a free game for kids, published by FranklyOpen
(franklyopen.com). It is built so that there is no personal data to
worry about:

- **No data is collected.** The game gathers no personal information, no
  usage analytics, no identifiers, no diagnostics — nothing, from anyone,
  of any age.
- **No data leaves the device.** The game makes no network connections
  at all. There are no accounts, no cloud saves, no telemetry, and no
  third-party SDKs (no ads SDKs, no analytics SDKs).
- **Progress stays on the device.** The only thing the game stores is a
  local save file (level progress, coins, and settings such as volume
  and question preferences) kept on the device itself. It is never
  transmitted anywhere. Deleting the app deletes it; the in-game
  settings screen can also reset it.
- **Almost no permissions.** The game requests no access to the camera,
  microphone, location, contacts, photos, or storage. On Android it
  declares only the vibration permission, used for gentle haptic tap
  feedback.
- **No ads, no purchases.** The game shows no advertising of any kind
  and sells nothing.
- **The grown-ups area** (question and age-band settings) sits behind a
  parental gate. Its settings are stored in the same local save file
  and, like everything else, never leave the device.

## Children's privacy

Cannonball Cove is designed for children, and the strongest protection
we can offer is structural: because the game collects no data and makes
no network connections, no personal information from children (or
anyone else) is ever gathered, stored off-device, shared, or sold. This
by construction satisfies the requirements of COPPA, GDPR (including
its rules for children), and the family policies of Google Play and the
Apple App Store. There is nothing to share with third parties, nothing
to delete on request, and nothing that could be used to contact, track,
or profile a child.

This applies to every version of the game on every platform (Google
Play, App Store, and any other distribution).
